# K Tech Solutions — Karan Desai

Portfolio site for **Karan Desai** (K Tech Solutions). Plain HTML + CSS + JS, no build step.
Live: https://ktechsolution-in.github.io/

| File | Purpose |
|---|---|
| `index.html` | All page content, SEO tags, JSON-LD |
| `styles.css` | Design (colours are variables at the top) |
| `main.js` | Menu, scroll effects, counters, contact form |
| `assets/` | Logo files; `assets/projects/*.webp` = project screenshots (640x400) |
| `karan-dp.jpg`, `og-cover.jpg` | Profile photo, link-preview image |

Edit stats: `data-count` / `data-suffix` in the About section of `index.html`.
Deploy: push to `main` — GitHub Pages publishes automatically.
